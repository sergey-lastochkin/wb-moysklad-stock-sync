# wb-moysklad-stock-sync

Сверка остатков **Wildberries (FBS)** с **МойСкладом** по одному или нескольким кабинетам продавца.

Типичная беда: в МойСкладе товара уже нет, а на складе продавца в WB висит старый остаток — приходят заказы, которые нечем собрать, и штрафы за отмены. Скрипт показывает такие позиции и, если попросить, аккуратно снижает остаток на WB.

## Что делает
1. Берёт остатки выбранного склада МойСклада (JSON API 1.2).
2. По каждому кабинету WB: карточки → баркоды → артикулы, остатки по всем складам продавца.
3. Сравнивает по артикулу и печатает, где **на WB больше, чем есть в МойСкладе**.
4. Сохраняет снимок «как было» в CSV.
5. Только с `--apply`: снижает остаток WB до значения МойСклада.

## Безопасность
- По умолчанию **только чтение**.
- Запись **только вниз** и не ниже нуля — поднять остаток скрипт не может.
- Артикулы, которых нет в МойСкладе, не трогаются, а выводятся отдельно.
- Перед записью — CSV-снимок, по нему можно откатить.
- Токены — только из переменных окружения, в код и репозиторий не попадают.

> ⚠️ Проверено на практике: если остатки на WB выгружаются не только с вашего склада, но и, например, со склада поставщика, сравнение с одним складом МойСклада покажет «лишнее» там, где его нет. Такие склады WB исключайте флагом `--exclude-warehouse`, а `--apply` запускайте только после просмотра отчёта.

## Запуск
Python 3.9+, без внешних зависимостей.

```bash
export MOYSKLAD_TOKEN=...      # токен МойСклада
export WB_TOKEN_SHOP1=...      # токен WB: «Контент» + «Маркетплейс»

python3 stock_sync.py --wb-token-env WB_TOKEN_SHOP1                         # отчёт
python3 stock_sync.py --wb-token-env WB_TOKEN_SHOP1 --wb-token-env WB_TOKEN_SHOP2 \
                      --store "Основной склад" --exclude-warehouse 123456   # несколько кабинетов
python3 stock_sync.py --wb-token-env WB_TOKEN_SHOP1 --apply                 # исправить
```

Пример вывода:
```
МойСклад: артикулов 812, с остатком: 640
== WB_TOKEN_SHOP1
  с остатком на WB: 305 · WB больше МС: 12 · нет в МС (не трогаем): 3 · снимок: snapshots/WB_TOKEN_SHOP1-20261008-101500.csv
    TOY-0417: WB 6 · МС 0 · склад Склад продавца
режим: только чтение (исправить: --apply)
```

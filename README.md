# wb-moysklad-stock-sync

сверяю остатки вб (FBS) с мойскладом. сделал после того, как у клиента на вб висели остатки, которых в мойскладе уже не было: заказы приходили, собирать было нечего, сыпались штрафы за отмены.

скрипт берёт остатки нужного склада в мойскладе, потом по каждому кабинету вб тянет карточки, баркоды и остатки по складам продавца, сравнивает по артикулу и показывает, где на вб больше, чем есть на самом деле. перед любой записью сохраняет снимок «как было» в csv, из него можно откатить.

по умолчанию он только читает. записывает только с `--apply`, только вниз и не ниже нуля, поднять остаток не может в принципе. артикулы, которых нет в мойскладе, не трогает, просто выводит отдельно. токены берёт из переменных окружения, в коде их нет.

кстати, проверено на себе: если на вб выгружаются ещё и остатки поставщика, сравнение с одним складом мойсклада покажет «лишнее» там, где его нет. такие склады вб исключайте через `--exclude-warehouse`, а `--apply` запускайте только после того, как посмотрели отчёт.

## запуск

нужен Python 3.9+, больше ничего ставить не надо.

```bash
export MOYSKLAD_TOKEN=...      # токен мойсклада
export WB_TOKEN_SHOP1=...      # токен вб с правами «Контент» и «Маркетплейс»

python3 stock_sync.py --wb-token-env WB_TOKEN_SHOP1                         # только отчёт
python3 stock_sync.py --wb-token-env WB_TOKEN_SHOP1 --wb-token-env WB_TOKEN_SHOP2 \
                      --store "Основной склад" --exclude-warehouse 123456   # несколько кабинетов
python3 stock_sync.py --wb-token-env WB_TOKEN_SHOP1 --apply                 # исправить
```

выглядит так:
